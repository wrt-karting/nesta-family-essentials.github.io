# NESTA — Family Essentials

A warm, modern static storefront for parents, babies, nursery organization, family travel, toys, care products and everyday organization.

## Included
- Responsive homepage and catalog
- 12 curated demo products
- Individual product pages
- Category collections
- NESTA Journal
- Saved products and localStorage cart
- Support center and FAQ
- Shipping, returns, privacy, terms and accessibility pages
- Local logo and image assets
- GitHub Pages-ready architecture
